# NetworkWalks B082 — Week 3: Password Security Assessment

## Project Overview

This project documents a practical **password security assessment** conducted as part of the NetworkWalks B082 Cybersecurity Training. The exercise focused on understanding password hashes, performing controlled password recovery, and evaluating password security within an authorized cybersecurity laboratory environment.

## Objectives

* Understand password hashing and password security concepts.
* Identify and analyse password hashes.
* Perform controlled dictionary-based password auditing.
* Use **John the Ripper (JtR)** to assess password strength.
* Analyse recovered results and identify potential security weaknesses.
* Develop practical skills applicable to ethical hacking and digital forensics.

## Tools & Technologies

* **Kali Linux**
* **John the Ripper (JtR)**
* **Linux command-line utilities**
* **Password wordlists**
* Virtualized cybersecurity laboratory environment

## Methodology

The assessment followed a structured workflow:

1. Prepared the authorized laboratory environment.
2. Identified and analysed the available password hashes.
3. Selected and configured an appropriate wordlist.
4. Conducted a controlled dictionary-based password audit using John the Ripper.
5. Analysed the resulting password-recovery output.
6. Documented the process, evidence, findings, and security implications.

## Key Outcomes

The exercise strengthened my practical understanding of **password hashing, password auditing, Linux security tools, credential security, and ethical password-recovery techniques**.

It also demonstrated how weak or predictable passwords can increase the risk of unauthorized access and highlighted the importance of strong password policies, secure password storage, and appropriate authentication controls.

## Skills Demonstrated

* Password security assessment
* Hash analysis
* John the Ripper
* Linux command-line operations
* Dictionary-based password auditing
* Ethical hacking fundamentals
* Digital forensics fundamentals
* Security evidence documentation
* Security risk analysis

## Ethical & Legal Considerations

All activities documented in this repository were performed within an **authorized and controlled cybersecurity laboratory environment for educational purposes**. Password-auditing techniques should only be applied to systems, credentials, or data for which explicit authorization has been granted.

## Conclusion

This Week 3 milestone provided valuable hands-on experience in **password security assessment and controlled credential auditing**, further developing my practical cybersecurity capabilities and preparing me for more advanced penetration-testing and security-assessment activities.
